# DZMM 搜索增强版

为 [DZMM](https://www.dzmm.ai) 提供更聪明搜索体验的浏览器扩展，Chrome / Edge 通用（Manifest V3）。

## 功能

- 在 dzmm.ai 页面右下角显示「增强搜索」悬浮按钮，页面内直接搜索
- 悬浮按钮与搜索窗口都可以随意拖动；搜索窗口还能在右下角拖拽调整大小，位置会自动记住（下次打开还是上次的位置）
- 点击浏览器工具栏的扩展图标，随时在新标签页打开完整搜索页
- 支持多关键词、精确短语、`#标签` / `@作者` 定向、`-排除词`、`min:赞数` / `rating:评分` 过滤，以及类型、时间、语言、敏感内容等筛选
- 直接输入作者名（如 `猫妖`）会自动识别为作者，只显示 TA 的卡片，也可点“取消过滤”查看全部关键词结果
- 抓取更快：多条数据流并行拉取、同一查询的结果在本次会话内缓存、切换搜索会立即取消旧请求，遇到限流会自动放慢重试
- 「在当前结果中快速筛选」：不重新请求接口，直接在已抓取的结果里按多个关键词缩小范围
- 搜索结果可以复制成链接列表或导出 CSV
- 独立的「比赛卡」页面：查看当期创作比赛（月赛）的参赛作品，支持按分组、按热门 / 最新排序，并可在已加载结果中搜索、复制列表或导出 CSV
- `web/` 目录提供无需安装的单文件网页版（桌面版 / 移动版）

## 安装（Chrome / Edge）

1. 下载代码并解压到固定位置（扩展运行时需要这些文件，不要删除）
2. Chrome：打开 `chrome://extensions`，开启右上角「开发者模式」，点击「加载已解压的扩展程序」并选择本文件夹
3. Edge：打开 `edge://extensions`，开启左侧「开发人员模式」，点击「加载解压缩的扩展」并选择本文件夹
4. 打开 https://www.dzmm.ai ，右下角就会出现「增强搜索」按钮

## 网页版（无需安装）

不想安装扩展也可以直接打开网页版入口页，页面会自动检测并推荐当前可用的地址：

- 网页版：[page-asserts.godsbee.com/pages/ntglefa1/index.html](https://page-asserts.godsbee.com/pages/ntglefa1/index.html)

仓库 `web/` 目录里也保留了可离线打开的单文件网页版（桌面版 / 移动版）。

## 搜索语法示例

| 输入 | 效果 |
| --- | --- |
| `白丝 病娇` | 同时包含两个关键词 |
| `#病娇` | 必须包含标签「病娇」 |
| `@猫妖` | 只查看该作者的卡 |
| 直接输入 `猫妖` | 自动识别为作者，只显示 TA 的卡（可点“取消过滤”看全部关键词结果） |
| `-NTR` | 排除包含 NTR 的结果 |
| `min:1000` | 至少 1000 赞 |
| `rating:4.5` | 评分不低于 4.5 |
| `"校园 老师"` | 精确短语 |
| `type:game` | 只看游戏卡 |
| `date:week` | 只看一周内 |

## 目录结构

```text
dzmm-better-search/
├── manifest.json        # 扩展清单（Manifest V3）
├── app.js / content.js  # 搜索逻辑与页面注入脚本
├── competition.*        # 比赛卡页面
├── search.html          # 完整搜索页
├── style.css            # 样式
├── icons/               # 扩展图标
└── web/                 # 单文件网页版（桌面 / 移动）
```

## 注意事项

- 搜索数据来自 dzmm.ai 公开接口，接口有频率限制；连续大量抓取时如果提示限流，等 30~60 秒再搜，或把「抓取深度」调小
- 扩展更新时：在扩展管理页点击「重新加载」即可
